# Crates that can reduce the Rust code

Checked on 2026-09-27. This note uses the published crate documentation, the crate source, and the beets documentation. Line counts refer to the current source files. They are estimates of code that a change can remove, not estimates of binary size or work time.

## 1. Use `lsap` for track assignment

**Status:** The project now uses [`lsap` 1.0.2](https://docs.rs/lsap/latest/lsap/) instead of the copied solver. This was the only direct replacement found in this review.

The previous `muzik-match/src/lsap.rs` was a copy of `lsap` 1.0.2. A comparison with the [published 1.0.2 source](https://docs.rs/crate/lsap/1.0.2/source/src/lib.rs) found the same solver logic, including the reverse column order that gives an identity assignment for equal costs. The local copy changed `solve` from public to crate-private and changed the two error variants to static strings. The published [`solve` API](https://docs.rs/lsap/latest/lsap/fn.solve.html) takes the same row count, column count, flat `Vec<f64>`, and maximize flag. The call is in [`ranking.rs`](../../rust/crates/muzik-match/src/ranking.rs). `lsap` 1.0.2 is the latest version shown by its published documentation. The package [declares MIT and `derive_more` 0.99.17](https://docs.rs/crate/lsap/1.0.2/source/Cargo.toml).

The change removed **221 lines** in `lsap.rs`. It added one dependency and changed [`Error::Assignment`](../../rust/crates/muzik-match/src/distance.rs) to hold `LSAPError`. The lockfile added five packages, including `derive_more` 0.99.20. The NOTICE files now identify `lsap` as a dependency. Keep the current rectangular, equal-cost, and beets parity tests. Equal-cost tests matter because several optimal assignments can have different track orders. The direct source comparison supports parity for 1.0.2; a future crate version needs a new check. The version is pinned because the package has had no newer published version.
